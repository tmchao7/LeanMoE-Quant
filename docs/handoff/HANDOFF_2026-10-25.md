## 2. S2 执行手册（下一次开机照单干；一轮一变量——**本窗口只做 F4**）

新开关命名：**`LEMOQ_KV_DIRECT_WRITE`**，进 `src/lemoq/kernels/fusion_switches.py` 的
`ENV_VARS`/`FUSION_DEFAULTS`（默认 **False**——先 A/B 后翻默认，同 F1/F2 的路数）。

**两条路线（选一条实现）**：

1. **RoPE 融合内直写**（推荐）：fused RoPE kernel 已在寄存器里算出 rope 后的 k，顺手
   `store` 进 cache 的 `[pos]` 槽；v 由 v_proj 后单独直写（或一个小 copy kernel）。省掉
   `update()` 的 `index_copy_` 整链（32 次/步）。
2. **attention kernel 内 in-place append**：让 `_attn_split_kernel` 直接读 cache 满长 buffer、
   由 `_lemoq_filled_len`（设备端取值机制已在）界定有效长度，k/v 写合并进 kernel。

   选 1 的理由：改动面小、与 fused RoPE 天然耦合（F1 已默认开）、K 门参照就是逐位切片写；
   选 2 动 attention kernel 主体，风险与 S2"一轮一变量"冲突。**默认按 1 实施**，若 K 门
   不过再评估 2。

**步骤**：

1. **体检**：四门（Mac 期望 700 passed；盒子语义 693+7 skipped，7 条为"无 triton/CUDA"互斥
   用例）→ `nvidia-smi --query-compute-apps=…` 查共租（只记录不 kill）→ `git pull --no-rebase`。
2. **实现**：kernel + `fusion_switches` 注册 + `attn_decode` 接线（开关关 = 原路径逐位不变；
   开关开 = 走直写）。**回退必须显式**：非 decode 形状/非 kernel 路径/CPU 一律回
   `past_key_values.update()`，不静默算错。
3. **K 门（GPU）**：`pytest tests/test_kv_direct_write.py`（原样，不许改断言）——kernel 版
   直写必须与 HF `update()` 逐位相同；再全套 `pytest -m "not gpu"` + 四门。
4. **合规 A/B**：`scripts/rounds/run_ab_fresh_process.sh`（独立进程、相邻、`PAIRS=5`——F4 的
   逐对差应很稳，5 对让显著性块更有底）；canary ≤5% + 逐 run host_share ≤5% +
   `tokens_equal`。注意：开关默认是 False，off 臂无需 ENV_OFF；**翻默认之后**重跑 A/B 必须给
   `ENV_OFF="LEMOQ_KV_DIRECT_WRITE=0"`（脚本 fail-closed 会拦）。
5. **刷新轮**：F4 作用域 = 所有 cudagraph 格（都写 cache）⇒ `F2=1 KV=1 bash
   scripts/rounds/run_f1_refresh.sh`（脚本需扩一个开关位——**改脚本单独 commit**，沿用
   显式 0/1 写法与断点对账）；`tools/round_canary head tail --graph --mark` 退出码 0。
6. **翻默认 + 同步**：无 env 双格金丝雀（kernel 格 `config` 里新开关生效=true；sdpa 格同样
   生效——F4 不依赖 attn 实现的话两格都该 true，以实测为准）→ 翻 `FUSION_DEFAULTS` →
   按 ADOPTION_SYNC 惯例同步数字（新起 `ADOPTION_SYNC_2026-10-25.md` 映射表）→ rsync 回传 →
   merge main。
7. **账本重算**：`tools.operator_ledger` 对新 canonical payload——kv_write_idx 应从榜上消失
   （gap≈0），下一轮第一名浮现。
