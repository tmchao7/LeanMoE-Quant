## Hypothesis（跑之前写）

```text
两个信号（EXP-p1-01 实测）：
  信号 1  W8A16 的 group_size 非单调：g32 0.0348 < g128 0.0268 < g64 0.0377
  信号 2  W4 attention 悬崖：W8 0.0268 → W4 4.271，差 160×，而"典型 RTN 的 W4/W8 是 2–4×"

两个互斥解释：
  H-缺陷  量化实现里有与 group_size / 位宽相关的缺陷
          （分组划分、打包、scale 存储、codes 与 scale 错位）
  H-敏感  实现正确；KL 是 16 层非线性放大的结果，且这个指标在该量级没有分辨力

跑之前冻结的判据（任何一条成立即支持 H-缺陷）：
  a) 权重域 rel_fro 随 group **非**单调
  b) 逐元素 |err| > s/2
  c) W4/W8 的误差界之比 ≠ (2^7−1)/(2^3−1) = 18.143
  d) 打包/反量化往返与参考不一致
  e) 只量化 1 层时，KL 的 group ordering 消失（说明是 16 层累积的假象）

需要新增的对照（不是判据，是**尺子**）：
  f) 同一误差量级、不同扰动方向 → KL 的散布 = 这个指标的噪声地板
  g) 把 W8 的误差按 18.143 放大但**不给** W4 的分组结构 → 能否复现悬崖（量级 vs 结构）

反证信号：若 (a)-(e) 全不成立，则"过不了门"不能归因给实现，但也不能因此放宽门 ——
           门是文档定的，必须原样记 FAIL。
```

## Method（为什么值得信）

1. **同轨迹 teacher forcing**（`benchmarks/quant_gate.py`），KL 用与 `EXP-p1-01` **同一个**
   `compare_logits`。
2. **复现是逐位相同的**：`trajectory_matches_published = true`，而且 attn+exp 的**六个格**
   （W8A16/W4A16 × g32/64/128）与 `EXP-p1-01` 的 KL **逐位相等**（全精度比较：
   `0.034818284213542938` vs `0.03481828421354294` 等，6/6）。
   → 整条管线（bf16→fp16 载入、per-group RTN、fp16 scale 打包、teacher-forced 解码、
   fp32 KL）是**确定性可复现**的。所以下面所有差异都是**结构性**的，不是运行间噪声 ——
   这也正是为什么"group 非单调"需要一把**别的尺子**（方向散布）来判断它有没有意义。
3. **空臂自检**：每个 arm 之前从 CPU 快照恢复权重，`noop` 臂"恢复但不扰动"的 KL 必须**恰好 0.0**。
   本轮共 12 个 noop 臂（主运行 3 + 敏感性 3 + 逐投影 3 + 自检 3），**全部 0.0**；
   `reference_self_kl = 0.0`。
4. **三层证据**：每个臂同时记录 —— 权重域 `rel_fro`（因）、**逐层输出相对误差**（放大在哪）、
   KL 与逐位置 KL（果）。
5. **权重域审计不加载模型**：按名字从 safetensors 惰性读张量，197 个真实张量全覆盖。
   注意口径：**checkpoint 是 bf16，而 pipeline 先转 fp16 再量化** —— 审计必须跟着转，
   否则量的是另一个张量（这条是本次实测踩出来的）。

## 结果 1：信号 1 = **指标没有分辨力**（H-敏感）

### 1.1 因（权重域）严格单调

| 作用域 | W8 `rel_fro` g32 / g64 / g128 | 单调？ |
|---|---|---|
| attention-only（加权） | 0.005513 / 0.006178 / 0.006820 | ✅ |
| attention+experts（加权） | 0.005494 / 0.006164 / 0.006817 | ✅ |
| 层0 全部 64 个专家的 192 个张量 | 中位数 0.005436 / 0.006056 / 0.006634 | ✅ **192/192** |
| 同上，W4 | 中位数 0.098464 / 0.109730 / 0.120260 | ✅ **192/192** |

三条不变量全部成立（197/197 张量）：**分组嵌套**（细组 absmax ≤ 粗组）、**逐元素界**
`|err| ≤ s/2`、**W4/W8 界比 ≡ 127/7**。判据 (a)(b)(c)(d) 全部**不成立**。

### 1.2 果（KL）非单调，而且**单层量化也复现同一个 ordering**

| 作用域（W8A16） | g32 | g64 | g128 | 形状 |
|---|---|---|---|---|
| attention-only | 0.036955 | **0.040553** | 0.023469 | g64 最差 |
| attention+experts | 0.034818 | **0.037734** | 0.026837 | g64 最差 |
| **只量化第 0 层** | 0.036610 | **0.038444** | 0.037538 | g64 最差 |

判据 (e) **不成立**：只量化 16 层里的 1 层，g64 仍然最差 → 不是 16 层累积出来的假象。
而同一批臂的**层 0 输出相对误差**是严格单调的（0.007215 / 0.008329 / 0.009279）——
翻转发生在层 0 之后，也就是发生在非线性里。

### 1.3 ★ 决定性对照：同一误差量级下的**方向散布**远大于 group 之间的差

固定误差量级（λ=1，即 W8 实现误差的逐张量 RMS），只换随机方向 ε：

| 方向 | `rel_fro` | 层0 输出误差 | KL |
|---|---|---|---|
| dir0 | 0.0067757 | 0.007592 | 0.027846 |
| dir1 | 0.0067757 | 0.007797 | 0.031187 |
| dir2 | 0.0067757 | 0.007995 | **0.525896** |
| dir3 | 0.0067757 | 0.007683 | 0.040121 |

**同一量级下 KL 散布 18.9×**；而 group 从 32 到 128 的 KL 散布只有 **1.73×**。
量级本身只差 1.24×（rel_fro 0.005513→0.006820），按同方向扫 λ 的局部斜率
（λ=1→1.2，量级 +20%，KL 只 +5.4%）外推，group 的差异**只该值 ~6%**，实测是反向的 1.73×。

→ **"g64 比 g128 差"落在方向抽签的散布里，不是一个可测的信号。**
`EXP-p1-01` 的假设 `group↓ → KL↓` 应该记为**无法在该指标上检验**，而不是被否证。

### 1.4 顺带解释了 AWQ 的前提

离群统计（真实权重）：attention 的 `absmax/RMS` 的 p95 = 3.94–5.55（高斯对照 ≈3.2–4.0），
**单个元素主导的组占比 0.0002–0.0056**，误差平方和的 top-1% 份额 0.021–0.099；
192 个专家张量的中位数更低（dyn_p95 3.62、单元素主导 0.0001、top-1% 份额 0.006）。
→ **没有"一个离群值把整组压成 0"这个经典失效模式。** AWQ 档的动机不在这里。
但 W4 把**逐输入通道的最大相对误差**从 0.018–0.074 抬到 **0.29–0.84**（7–10× 的尾部）——
通道级 remedy 有机制依据，量级有限。

## 结果 2：信号 2 = **量级 × attention 通路的非线性**（H-敏感）

### 2.1 算术：18.143 不是"2–4×"

W4/W8 的误差**界**之比恰好 `(2^7−1)/(2^3−1) = 127/7 = 18.143`（实测各张量 17.7–18.1）。
这不是缺陷，是**定义**：位宽减半，步长按 `qmax` 之比放大 18 倍。
"典型 W4/W8 差 2–4×"说的是 **KL 的经验比**，不是权重误差比 —— 两者不能混。

### 2.2 同一条 18× 的因，在两条通路上给出差 17 倍的果

| target（g128） | W8 KL | W4 KL | KL 比 | W8 `rel_fro` | W4 `rel_fro` | 因之比 | W8 层0 | W4 层0 | 层0 之比 |
|---|---|---|---|---|---|---|---|---|---|
| attention only | 0.023469 | 4.270599 | **182×** | 0.006820 | 0.123570 | 18.1× | 0.009279 | 0.161642 | 17.4× |
| experts only | 0.039317 | 0.408039 | **10.4×** | 0.006575 | 0.119170 | 18.1× | 0.001322 | 0.022287 | 16.9× |

两条通路的**因**一样（18×），**果**差 17 倍：attention 的放大指数
`log(182)/log(17.4) ≈ 1.8`（超线性），专家路径 `log(10.4)/log(16.9) ≈ 0.8`（亚线性）。
→ **attention 通路每单位相对权重误差的 KL 敏感度是专家通路的 ~17×。**

### 2.3 ★ 决定性对照：纯噪声在 W4 量级就复现了整条悬崖

把 W8 的逐张量误差按 18.143 放大（i.i.d. 噪声，**不带** W4 的分组/离群结构）：

| 臂 | `rel_fro` | 层0 输出 | KL | 逐层曲线（前 5 + 末） |
|---|---|---|---|---|
| 真实 `w4a16` attention g128 | 0.123570 | 0.161642 | 4.270599 | 0.162 / 0.300 / 0.521 / 0.764 / 0.982 … 1.678 |
| `noise λ=18.143` | 0.122930 | 0.138040 | **4.404794** | 0.138 / 0.276 / 0.562 / 0.826 / 0.990 … 1.583 |

噪声的 `rel_fro` 与真实 W4 几乎相同、层 0 输出误差还**更小**（0.138 vs 0.162），
而 KL 更高（4.40 vs 4.27），逐层曲线几乎重合。
→ **悬崖由量级完全解释；RTN 的结构（分组、离群塌缩）没有任何额外放大。**
判据 (g) 支持 H-敏感。

悬崖的机制也看得见：W4 attention 的逐层误差在 **4–5 层内从 0.16 涨到 ~1.0**
（相对误差 100% = 隐状态实质随机化）后进入平台；W8 是 16 层里从 0.0093 涨到 0.118（每层 ×1.17）。

### 2.4 ★ 逐投影：悬崖**全部**来自 v_proj 与 o_proj

同量级、只扰动一类投影（噪声，λ=1）：

| 只扰动 | dir0 KL | dir2 KL | 层0 输出 |
|---|---|---|---|
| `q_proj` | 0.000284 | 0.000368 | 0.0 |
| `k_proj` | 0.000284 | 0.000359 | 0.0 |
| `v_proj` | 0.004812 | **0.516645** | 0.0044 / 0.0046 |
| `o_proj` | 0.037729 | 0.004759 | 0.0063 / 0.0064 |

真实 RTN，W4 g128，只量化一类投影：

| 只量化 | KL | top-1 | 层0 输出误差 |
|---|---|---|---|
| `q_proj` | 0.001926 | 1.0 | 0.0 |
| `k_proj` | 0.001724 | 1.0 | 0.0 |
| `v_proj` | **4.059905** | 0.0 | 0.114827 |
| `o_proj` | **4.051414** | 0.0 | 0.124397 |

**W4 attention 的四类投影里，v_proj 单独就给出 4.06、o_proj 单独给出 4.05 —— 各自约等于
全部四类的 4.27；而 q/k 单独只有 0.0017–0.0019（比 W8 的 0.01 门还低 5 倍）。**

机制与 `q_norm`/`k_norm` + softmax 一致：**q/k 只进 attention 权重（小扰动下是二阶效应），
v/o 直接进被加权的 value（一阶效应）**。这同时解释了 1.3 的"方向抽签"为什么集中在
v_proj（dir2 的 0.517 就是它一个人贡献的）。

## Follow-ups

1. **EXP-p1-03（下一步）**：混合位宽 `q/k=W4, v/o=W8, experts=?` 过同一道门。本条的
   逐投影结果是它的输入；它必须标 `combined` 并自己过门。
2. **指标分辨力必须被标定后再用于比较方案**：KL 在 0.03 量级的方向散布 18.9×，
   所以"方案 A 的 KL 0.030 比方案 B 的 0.033 好"这种话**不能说**。
   以后比较量化方案应报**多方向/多种子**的散布，或改用更平滑的指标（PPL、logit MSE）。
3. **落盘命名（EXP-p1-01 follow-up 3 的真实形态）**：per-cell `result.json` 会被下一次
   同 id 的运行覆盖，而 `--json` 汇总写去别处 → 两处口径不同。要么让 cell 文件带上
   `targets` 指纹，要么让工具拒绝覆盖不同 spec 的同名 cell。
4. **`v_proj`/`o_proj` 为什么一阶敏感**值得单独量化：用 v/o 的**通道级**相对误差
   与 KL 做对照（本条的通道统计已经有了：W4 下 0.29–0.84）。
5. **bf16→fp16 的边界效应**（实测）：checkpoint 最小权重 9.5e-12，转 fp16 时 4376 个元素
   下溢成精确 0；`scale.half()` 对 subnormal 步长（absmax < 7.6e-6 的组）会舍入到 0。
   本模型上绝对量级可忽略（误差 < 1e-7，而张量尺度 ~0.05），但**换模型要重查**。
